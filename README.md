# スマホ覗き見

創作キャラや推しのスマホを、こっそり覗いている場面を作るツールです。
ロック画面 → ホーム画面 → 各アプリ、と実際にタップして中を見ていけます。
かわいい・甘い話から、ホラーまで使えます。

- 文章や画像は、自分で入れます。AIは使っていません。
- 通信はしません。入れた内容は、使っている端末のブラウザの中にだけ保存されます。
- HTMLファイルが1つだけです。インストールも、ビルドも要りません。

## 使い方

1. `index.html` をブラウザで開きます。
2. 上のタブで、名前・通知・検索履歴・メモ・メッセージなどを入れます。
3. 下の「スマホを覗く」を押すと、スマホの画面が開きます。ロック画面を上にスワイプして、中を見ていきます。
4. 「撮影用」を押すと、枠や操作を消した、画面録画・スクリーンショット向けの表示になります。

GitHub Pages で公開すれば、URLをブラウザで開くだけで使えます。
（リポジトリの Settings → Pages で、公開元に `main` ブランチのルートを選びます。）

## できること

- **ロック画面**：通知が順番に出ます。通知の音、白/黒の切り替え、通知を押してメッセージへ移動、スワイプ解除
- **ホーム画面**：メッセージ、写真、ブラウザ（検索履歴）、メモ、電話、カレンダー、時計、天気、マップ、カメラ、ミュージック、設定
- **メッセージ**：チャットの見た目。相手ごとのアイコン、送信取り消し、背景の色
- **着信**：解除から何秒後に出す、拒否/応答、アイコンのオンオフ（「不明な相手」の演出）、着信履歴
- **好きなアプリを足す**：家計簿やショッピングなどの、押しても開かない飾りアプリ
- **音**：通知音・着信音を、自分の音声ファイルに差し替え
- **見た目**：壁紙、スマホ本体の枠（黒・銀・青・なし）、カメラ部分（アイランド・ノッチ・なし）
- **共有コード**：内容を文字だけにして、友達に送れます

## 保存されるもの

- 保存先は、その端末のそのブラウザの中です。別の端末や別のブラウザには出ません。ブラウザのデータを消すと消えます。
- 文章の設定は `localStorage`、画像（壁紙・写真・アイコン）は `IndexedDB` に保存します。
- 別の端末に移したいときは、共有タブの「共有コード」を使ってください。

## 共有コードについて

- コードに入るのは**文字の内容だけ**です。画像と音は入りません。
- コードには、通知やメッセージなど、入れた文章がそのまま入ります。他人に見られて困る内容は、入れたまま共有しないでください。
- 受け取ったコードを読み込むと、いまの内容が置き換わります。

## ファイルの構成

```
index.html   … 本体（HTML・CSS・JavaScript が全部入っています）
README.md    … この説明書き
```

## 外部への接続

- 文字の表示に、Google Fonts（Dela Gothic One / Zen Kaku Gothic New / JetBrains Mono）を読み込みます。
- 読み込めなくても、標準の日本語フォントで動きます。
- それ以外の通信はありません。

## 注意

- 実在の企業・サービス・端末とは関係のない、非公式の創作ツールです。
- 見た目は、スマートフォンの画面を参考にした雰囲気だけのものです。
- 通知音の標準の音は、ファイルの中に埋め込まれています。公開・再配布するときは、その音を使ってよいものか、確認してください。
- 動作を確認したのは、パソコンのブラウザ（Chromium）です。スマホ実機では、まだ確認していません。
